# 萌芽宠物 SproutPet

一款 Android 养成类 App —— 领盲盒、孵蛋、养宠物、结婚生仔、建立家族族谱。

---

## 项目简介

**一款以「养一只会陪伴你的宠物」为核心的轻度养成应用。**

从一颗神秘盲盒蛋开始，经过孵化、破壳、成长、互动，最终走向结婚、繁育后代，形成可追溯的家族族谱。

### 核心特色

- **盲盒孵化**：5 档稀有度 + 保底机制，孵化时长 24h~72h，可用道具或"专注陪伴"加速
- **立体宠物**：基于 Rive 骨骼动画，会挤压拉伸、会有体积感，可拖拽、"被拎起"
- **真实互动**：宠物有状态机 —— 会累、会困、会睡着、会被冷落而不高兴
- **基因遗传**：每只宠物有 6 维基因，后代混合父母特征并有变异，"长得像爸妈但不完全一样"
- **社交繁殖**：成年后可结婚，伴侣可生育 5 个后代，支持跨族混血
- **族谱系统**：树形可视化，可追溯到第 N 代祖宠
- **家族与排行**：创建/加入家族，5 种排行榜

## 快速开始

### 环境要求

- JDK 17
- Android SDK（API 34）
- Android Studio Ladybug 或更高

### 编译运行

```bash
# 设置 JAVA_HOME（Windows Git Bash）
export JAVA_HOME="C:/Users/Administrator/.jdks/jbr-17.0.14"

# 编译
./gradlew assembleDebug

# 运行测试
./gradlew test

# 安装到设备
./gradlew installDebug
```

### 关键配置

`local.properties` 需指向你的 Android SDK：

```properties
sdk.dir=C\:\\Users\\<你的用户名>\\AppData\\Local\\Android\\Sdk
```

```
│       ├── network/            # 网络层
│       └── di/                 # Hilt 模块
│
└── docs/                       # 设计文档
```
