## ⭐ 网络环境诊断 + 切到 SSH(443) 通道（解决 Android Studio 无法 push）

### 实测结论（本机网络）
| 目标 | 结果 |
|---|---|
| `github.com:443` 直连 | ❌ TcpTestSucceeded=False（被阻断）→ 这是 Android Studio「Failed to connect to github.com port 443」的根因 |
| `api.github.com` | ❌ DNS 污染（返回 301/垃圾响应）→ IDE「Log in with Token」必然报 `Can't parse GitHub response`；GCM 同样挂 |
| `ssh.github.com:443` | ✅ **通**（TcpTestSucceeded=True） |
| 系统代理 | 未开启（ProxyEnable=0）；本机无任何 VPN/代理进程在跑（7890/7897/10809/1080 等端口全 False） |

### 解决方案（已落地）
1. `ssh-keygen -t ed25519` 生成 `~/.ssh/id_ed25519`（无口令）
2. 写 `~/.ssh/config`：`Host github.com` → `HostName ssh.github.com` / `Port 443` / `User git` / `IdentityFile ~/.ssh/id_ed25519` / `IdentitiesOnly yes`
3. 用户在 https://github.com/settings/ssh/new 添加公钥（注意：PAT 无 `admin:public_key` scope，且 API 不可达，只能手动加）
4. `git remote set-url origin git@github.com:wangliyang206/SproutPet.git` ✅ 已验证 fetch/push 正常

### 遗留说明
- **Android Studio 里的 GitHub 账号登录框永远用不了**（依赖 api.github.com），但**不需要**它：git 的 commit/push/pull 走 SSH 即可；仅「Share Project / Clone / PR」类功能受限。
- 若以后要修好 IDE 账号：需先开 VPN，再在 `Settings → System Settings → HTTP Proxy` 配手动代理。
