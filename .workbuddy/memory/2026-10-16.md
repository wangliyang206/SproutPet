## 环境坑点（重要）

1. 本机 WorkBuddy 沙箱会注入本地代理（http_proxy/https_proxy=127.0.0.1:随机端口），会让 git push 在认证阶段返回 **406 Not Acceptable**，且 `GIT_TERMINAL_PROMPT=1` 下无 /dev/tty 无法输入。
   - 解决办法：命令前加 `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY`，并用 `dangerouslyDisableSandbox` 执行。
2. Git Credential Manager（GCM）在本机网络环境下登录 GitHub 失败（访问 api.github.com 被污染，返回异常 301/406），IDE 的 "Share Project on GitHub" 同样报 "Can't get profile information"。
   - 结论：暂时用 Personal Access Token（repo 权限）直接推送最可靠：`git -c credential.helper= push https://<user>:<token>@github.com/<user>/<repo>.git main`。
